Khorana Calculator
Учебный настольный калькулятор для расчёта баллов по шкале Khorana — инструменту стратификации риска венозных тромбоэмболических осложнений (ВТЭО) у амбулаторных пациентов со злокачественными новообразованиями, получающих системную противоопухолевую терапию.

Версия: 1.1.0
Дата выпуска: 15.08.2026
Автор: Жихорев Р. С.

Назначение
Программа позволяет ввести исходные параметры пациента и сформировать текстовый отчёт с расчётом суммы баллов по шкале Khorana:

локализация опухоли;

количество тромбоцитов до начала химиотерапии;

концентрация гемоглобина и факт применения эритропоэз-стимулирующего препарата;

количество лейкоцитов до начала химиотерапии;

индекс массы тела, рассчитываемый по росту и массе тела.

Результат можно скопировать в буфер обмена для последующей проверки, документирования или учебного разбора.

Изменения в 1.1.0
Скорректирована обработка роста и массы тела при расчёте индекса массы тела.

Упрощено формирование текстового отчёта.

Унифицирована валидация числовых значений, вводимых пользователем.

Добавлена краткая ссылка на источник шкалы в интерфейсе программы.

Исправлены подписи полей, сообщения валидации и отдельные элементы форматирования интерфейса.

Запуск из исходного кода
Требуется Python 3 с доступным модулем Tkinter.

bash
python khorana_gui.py
Внешние Python-зависимости не используются.

Сборка Windows EXE
Для создания автономного Windows-приложения:

bash
python -m pip install pyinstaller
python -m PyInstaller --clean --onefile --windowed --name KhoranaCalculator khorana_gui.py
Готовый файл будет создан в папке dist.
